# Devtools Roadmap (Gateway)

01) Webhook Analysis (raw vs normalized)
02) Payload Inspector (schema + diff)
03) Controlled Replay (throttle + overrides)
04) Unified Timeline (channel/guest)
05) Idempotency Map (dedupe keys)
06) Error Panel (exceptions + HTTP)
07) Connection Simulator (event templates)
08) Provider Comparator (Evolution/WAHA)
09) Trace Correlation (request -> records)
10) Metrics Dashboard (volume + latency)
11) Gap Checklist (received vs implemented)

Notes
- Each item has a dedicated file with steps and scope.
- All features are dev-only and should not be required by production modules.
- Each feature has a config flag in Devtools > Recursos.
